# Smart Print Creator

preciso criar encartes igual a este da foto, nao quero usar um editor de imagens e sim automatizar o processo, onde pesquisaria pelo produto e apareceria a foto e eu colocaria o preço unitario. com isso ele ja teria o modo de embalagens pré cadastrado, pois eu subiria um arquivo com todos os produtos, embalgem, peso e preço pre definidos. em alguns caso eu poderia colocar ate mais de um produto e ele iam se ajustando para ficar organizado.
